# 调用日志与故障排查

适用于 **PG Proxy 0.4.0（版本码 40）**。日志功能已完成人工验收，并通过本轮 Python 回归与默认 Pixel 10 的打包应用、详情交互检查；各阶段结果分别记入[验证记录](VALIDATION.md#040--2026-11-01-调用日志与刷新交互)，不沿用历史版本的通过结论。

## 查看方式

在底部 **日志** 页查看最近 100 条记录。列表展示摘要，支持搜索、暂停显示、复制结果，以及成功、失败、信息、警告、错误五种级别筛选。暂停显示不会暂停请求或后台记录。

点击单条记录查看详情；请求还在处理中时，可刷新详情查看新状态。凭证异常单独标记，并关联本次请求标识。目录聚合时某份凭证失败、其他凭证仍成功的情况，会保留凭证异常记录，避免将整个目录请求误报为失败。

详情右上角的刷新按钮采用与概览一致的旋转反馈。刷新期间保留已有详情和列表位置，不插入进度条挤动正文；首次加载与刷新失败会显示对应状态，并支持重试。列表与详情都可复制脱敏内容。

## 记录内容

| 信息 | 说明 |
| --- | --- |
| 调用定位 | 内部生成的请求标识、调用时间、方法、脱敏接口地址 |
| 请求摘要 | 模型、流式选项、受支持的数值设置、消息或内容数量；不保存对话正文 |
| 处理过程 | 已到达的处理阶段，以及实际发生的上游请求摘要 |
| 调用结果 | 客户端响应状态码、耗时、成功或失败状态 |
| 错误详情 | 错误分类、业务错误码、上游 HTTP 状态及经过脱敏、限长处理的原始错误信息 |
| 凭证异常 | 会话缺失、无可用凭证、会话失效或鉴权失败；不展示 Cookie 或登录账号邮箱 |
| 网络线索 | 失败时已有的概览网络快照、缓存时间与排查提示 |

请求刚进入应用时先记录为处理中，结束后更新同一条记录。流式响应已经发出 HTTP 200 后仍可能中断，因此应同时查看**调用结果与错误信息**；不能只凭 HTTP 200 判断生成完成。客户端断开、任务取消与上游异常分别记录。

如果连接在响应头发出前中断，客户端响应状态保持未知，不会为了填满日志而编造 HTTP 500。错误自身对应的业务状态与客户端实际响应状态分别展示。

上游拒绝访问不必然意味着 Cookie 过期。尤其 HTTP 403 可能涉及权限、地区或请求校验，应结合阶段与上游原始错误处理。请求在连接阶段失败、尚未收到响应时，详情不会编造上游状态码。

缺少 Google 签名 Cookie 与已有签名 Cookie 过期会分别记录；单个凭证尝试失败后，其他凭证仍可能完成模型目录请求。错误详情只使用本次失败明确携带的上游状态，不会把前一个凭证的 HTTP 503 归到后续参数错误上。完整尝试过程仍可在上游调用记录中查看。

## 网络判断的边界

失败日志读取概览页已有的缓存，不主动刷新，也不会自动切换网络或重复生成。

- 地区提示使用项目在 **2026-10-29** 核对的区域记录，规则变化时以 [Google 官方支持区域](https://ai.google.dev/gemini-api/docs/available-regions?hl=zh-cn)为准。
- 风险分达到 **75/100** 时显示提示，这是本项目的排查提醒阈值，不是 Google 的封禁标准；缺少风险分时保持未知。
- 缓存超过五分钟会标为过时；可回概览页刷新，再核对实际出口。
- 查询服务与 Google 可能走不同路由。地区、机房标记或高风险分都是排查线索，不能单独证明本次失败原因；低风险也不能证明可用。
- 本地 API 密钥错误、参数问题、错误地址等，不应归因于网络地区。

## 隐私与保留范围

日志只保存本次后端进程的有限内存记录，服务进程重建后清空；不自动上传，不写入永久日志文件。详情通过 Android 私有进程通信获取，没有新增对局域网开放的日志管理接口。详情按需读取，避免常规状态刷新携带大量错误正文。

不记录 Authorization、接口密钥、Google Cookie、WAA proof、提示词正文、生成正文或媒体内容。请求参数采用白名单摘要，错误文本会脱敏、限长；HTML 页面不会作为完整错误正文保存，网络快照中的公网 IP 会遮挡。分享复制的详情前仍应检查其中是否有不愿公开的信息。

脱敏也覆盖上游错误中回显的提示词片段。为限制内存占用，私密内容匹配有预算；超过预算、无法完整覆盖待检查内容时，会隐藏相应原始文本，继续保留结构化状态码、错误类型与处理阶段。日志预算不会改变正常 API 的请求参数，也不会触发生成重试。

| 保留项 | 上限与截断行为 |
| --- | --- |
| 调用与管理记录 | 最近 100 条，旧条目被替换后详情不可再读取 |
| 单次请求的上游调用 | 最近 12 次，超过后显示截断说明，保留最近失败尝试 |
| 单次请求的阶段轨迹 | 最多 24 条，超过后标记截断；当前处理阶段单独保留 |
| 主错误原文 | 正文最多 2048 字符，可能因脱敏预算或敏感内容更早隐藏 |
| 每条上游错误摘要 | 正文最多 1024 字符；不是完整响应正文 |

因此“原始错误”指经过脱敏与限长处理的诊断信息，不是未经处理的上游响应或完整抓包。

记录范围是**到达应用层的 HTTP 请求**，包括错误路径、方法、认证与参数拒绝。连接未建立、HTTP 解析失败、Uvicorn 并发上限在应用层之前返回的拒绝、进程被系统终止等，可能没有完整调用记录。没有日志时，应继续核对客户端地址、监听状态、局域网和系统后台限制。

概览统计仅统计已有定义内的模型目录、模型详情、计数和生成接口；日志还包含健康检查、错误地址等记录，两者数量不要求相同。

## 排查与回归清单

人工验收已通过；以下清单同时用于后续回归和问题复现。每次发布的实际执行项目与环境，以对应[验证记录](VALIDATION.md)为准。

| 场景 | 应检查的日志信息 |
| --- | --- |
| 客户端使用错误密钥 | 接口地址、401、鉴权分类；错误密钥不出现在摘要或详情中 |
| 请求不存在的路径 | 原请求方法与脱敏路径、404、具体原因 |
| 提交不能解析的 JSON／缺少实际必需内容 | 参数或请求体阶段、400、错误说明；不泄露提交正文 |
| 已接受请求后断开上游网络 | 连接／超时分类、失败阶段、耗时；未收到上游响应时不伪造状态码 |
| 无可用凭证／会话不再有效 | 独立凭证提示和相关请求标识；不能把所有 403 都认定为过期 |
| 上游响应错误或流式中断 | 上游状态、业务错误码、脱敏原始原因；HTTP 200 的流错误也显示失败 |
| 正常模型目录或生成 | 成功级别、响应码、耗时；不显示对话或生成内容 |
| 查看、暂停、筛选、复制、刷新详情 | 列表位置和筛选状态保留，内容脱敏；旧记录淘汰后有明确提示 |

网络异常、凭证异常与流式中断的自动化检查使用受控故障注入；它们验证日志和清理行为，不等同于重新验证真实 Google 会话、模型生成或真机网络环境。
