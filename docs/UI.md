# 界面与交互

PG Proxy 采用蓝灰色主题、分组卡片和底部导航，提供跟随系统、浅色、深色三种外观。

## 页面分工

| 页面 | 主要内容 | 交互说明 |
| --- | --- | --- |
| 概览 | 服务开关、凭证与请求统计、连接地址、网络信息 | 服务断连时保留上次信息并提示恢复，暂时禁止服务操作；重复轮询不重复弹出提示 |
| 凭证 | 添加、继续登录、启用、检查、重新登录、删除 | 导入成功与生成检查通过分别显示；检查会调用真实模型；删除和清除未完成登录需确认 |
| 日志 | 最近 100 条管理事件，支持筛选、搜索、暂停和复制 | 暂停仅影响显示，后台仍记录；复制内容经过脱敏；搜索期间不播放重排动画 |
| 设置 | 端口、局域网、密钥、超时、后台运行、主题及项目入口 | 非法输入及时提示，后台刷新不会覆盖未保存的表单；另提供诊断、许可和登录资料清理 |

设置中的项目入口包含仓库、问题反馈与 QQ 群名片。后台运行设置提供通知、电池优化、厂商设置入口和默认关闭的 CPU 唤醒选项；系统设置入口在服务断连时仍可使用，详见[后台运行](BACKGROUND_RUN.md)。

设置页和凭证页均提示“请求逐个执行”：凭证轮询不代表多账号并发生成。排队超时限制的是开始执行前的等待时间，上游读写超时另行计算，详见 [FAQ Q12](FAQ.md#q12如何添加多个账号轮询会自动解决额度限制吗)。

## 排版与图标

正文、辅助说明和操作使用统一的字号、行高与颜色，不额外打包字体。大字体下，统计、网络地址和按钮自动分行；页面与弹窗可滚动，底栏不遮挡最后一项操作。

应用图标采用蓝底烧瓶与镂空星，通知使用透明背景的单色同款图案。Android 状态栏通常显示通知小图标，部分厂商会使用带主题的应用图标。vivo 真机曾因系统图标缓存显示旧 P 图案，刷新缓存后恢复；无需为此卸载应用或清除凭证，排查方法见 [FAQ](FAQ.md)。

## 动效

| 场景 | 行为 |
| --- | --- |
| 按压 | 90 ms 内缩放至 97.5%，释放使用短弹簧动画；取消手势不触发业务操作 |
| 切换页面 | 按方向移动 16 dp，约 200 ms 完成；底栏胶囊可随连续点击改变动画方向 |
| 常规反馈与主题 | 常规反馈约 120 ms，主题颜色过渡约 280 ms；跟随系统动画倍率，关闭动画后仍可操作 |
| 快速交互 | 退场页面和凭证条目不接受触摸或无障碍操作；切页保留表单、日志暂停和筛选状态 |
| 刷新 | 图标提供有限反馈，加载状态由实际请求结果驱动 |

## 验证与设计来源

`UIInstrumentedTest` 和 `MotionInstrumentedTest` 使用空白 Compose 宿主、合成状态及内存回调，不访问 Google 或真实凭证。覆盖深浅色、320 dp 窄屏、1.6 / 2 倍字体、动画中间帧、快速反转、按压取消及零动画倍率。运行命令与已记录结果见[验证说明](VALIDATION.md)。

信息层级和卡片布局最初参考 FlClash。界面与动画由本项目使用 Compose 实现，未引入 FlClash 代码、图片或商标；相关来源见[来源说明](SOURCES.md)。
