# PG Proxy 0.4.0

让每次调用都有记录，让失败原因更容易找到。

**版本：0.4.0 · 版本码：40 · Android 9+ · arm64-v8a**

[下载安装包](https://github.com/print-yuhuan/PG-Proxy/releases/tag/v0.4.0) · [使用说明](../../README.md#快速开始) · [调用日志说明](../REQUEST_LOGGING.md) · [问题反馈](https://github.com/print-yuhuan/PG-Proxy/issues)

## 更新内容

- **补齐 API 调用日志。** 请求到达应用层即建立记录，完成后更新结果，包含时间、接口地址、关键参数摘要、HTTP 状态与调用耗时；错误密钥、错误地址和参数拒绝也能追溯。
- **失败环节更清楚。** 区分连接异常、请求超时、鉴权失败、参数错误、上游 5xx、排队与流式中断；保留脱敏后的原始错误、业务错误码和实际处理阶段。流式响应已返回 HTTP 200 后再失败，也会显示失败结果。
- **凭证异常单独提示。** 会话缺失、失效或被拒绝的情况独立记录，并关联对应请求；区分客户端接口密钥与 Google 会话、签名 Cookie 缺失与过期，不将所有 403 都认定为 Cookie 过期。最终失败不会误用其他凭证先前返回的 HTTP 状态。
- **结合已有网络信息排查。** 失败详情附上概览页缓存的地区、查询时间与风险分。过时缓存会提示刷新；地区和风险分仅作为线索，不直接认定故障原因，也不会触发额外查询或自动重发生成。
- **新增可点击的日志详情。** 列表保留精简摘要，支持成功、失败、信息、警告、错误五级筛选，以及搜索、暂停和复制。点击记录查看完整脱敏详情，支持刷新、重试与返回。
- **修复刷新时的页面跳动。** 日志详情使用与概览一致的按钮旋转反馈，刷新时保留已有内容和滚动位置，避免进度条出现、消失造成正文上下挤动。
- **补强错误信息脱敏。** 过滤上游错误中回显的长提示词片段；敏感数据匹配预算耗尽时隐藏原文，继续保留结构化错误码与处理阶段，不影响请求本身的正常处理。

日志只保留本次后端进程最近 100 条记录；单次请求最多保留最近 12 次上游调用与 24 条阶段轨迹。详情按需读取，不新增对外日志管理接口。密钥、Cookie、WAA proof、对话正文和媒体内容不作为日志保存；主错误原文限 2048 字符，上游分段摘要限 1024 字符，并按敏感内容进一步脱敏或隐藏。

## 安装与升级

下载附件 `PG-Proxy-0.4.0-arm64-v8a-release.apk`，使用现有正式签名，可覆盖同签名的 **0.2.0／0.3.0／0.3.1** 正式版本。常规升级不需要卸载或清除数据，原配置和凭证会保留；Google 会话本身仍可能到期。

旧 0.1.0 或自行构建的不同签名包，请先核对[安装与签名说明](../MAINTENANCE.md#安装与后续更新)。本次提供 ARM64 安装包，不适用于 32 位 ARM 手机。

公开附件包含安装包、`SHA256SUMS.txt` 与 `BUILD_INFO.json`。请以清单记录的实际源码提交、APK 哈希与签名证书指纹核对文件；正式签名不等于第三方安全认证。

打包应用检查实际监听端口、错误密钥、错误地址、参数拒绝和私有详情访问；其中一个测试方法还执行 7 个受控凭证、网络与流式故障场景，已计入上述 72 项，不重复累计。详情刷新验证正文位置保持不变、图标旋转后归位且停止，失败重试和列表状态恢复正常。具体环境、安装包哈希与修复记录见[0.4.0 验证记录](../VALIDATION.md#040--2026-11-01-调用日志与刷新交互)。

日志覆盖进入应用层的 HTTP 请求；连接未建立、HTTP 解析失败、Uvicorn 在应用层之前拒绝的并发请求，以及进程被系统终止时，可能没有完整记录。第三方网络查询与 Google 可能使用不同出口，网络风险分不是 Google 的限制标准。

本轮仅使用默认 Pixel 10 模拟器，未操作真机。连接异常场景包含 Android 回环地址的真实连接拒绝，其余上游错误使用受控响应；这些结果用于验证日志行为，**不代表重新完成真实 Google 登录、模型生成或长期后台运行验证**。ARM64 正式包的构建、签名和组件校验资料随 Release 附件提供；本轮未在 ARM64 设备安装运行，不能以 x86_64 Debug 结果代替。
