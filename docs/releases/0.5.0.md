# PG Proxy 0.5.0

版本码 **50**，支持 Android 9 及以上版本。构建支持 `arm64-v8a` 和 `x86_64`。

## 接口与运行时

- 校验 Playground 流尾状态后才发出成功结束标记。首个业务输出前的异常返回 HTTP 错误，已经开始的流用原格式返回错误并计入失败。原生安全拒绝和用量继续输出，原始上游结束文案由公开错误字段替代。
- SSE 开始输出后，空闲满 15 秒发送注释心跳。Gemini 的 JSON 流继续输出合法 JSON，断开连接后释放上游读取和账号队列。
- 凭证冷却支持秒数和 HTTP 日期。最早恢复时间超出请求排队期限时，返回 `429 / rate_limit` 和剩余等待时间。生成和协议允许的续写沿用同一次请求的凭证。
- OpenAI 和 Gemini 工具调用支持超过 63 个 UTF-8 字节的工具名。生成和真实计数共用映射，公开响应恢复原名并保留调用 ID 与思考签名。函数结果按 JavaScript 对象键序编码。
- 模型在线目录宣告 `EXTRA_HIGH` 时可选用该档位。缺少对应档位时，仅在模型支持 `HIGH` 的情况下回退到 `HIGH`。
- 修复 WAA 非 UTF-8 严格解码中的有效替换字符与非法序列判定。更新 URL 解析使用的 IDNA 依赖，并降低内联附件 Base64 规范化的临时内存峰值。

## 安装与验证

**0.5.0 使用新的正式证书，无法直接覆盖安装到 0.4.0 及更早的正式包。** 如需升级，请先记录必要设置，再卸载旧包、安装 0.5.0 并重新登录。卸载会删除旧包的本地配置、凭证和 Gecko 会话。[安装与签名](../MAINTENANCE.md#安装与后续更新)

已在 Pixel 10 x86_64 Debug 包上通过 Android 回归和单凭证真实验收，覆盖两套生成接口、WAA 强制刷新和 20 项 HTTP 检查。ARM64 真机安装、真实双账号轮询、真实配额冷却和跨 32K 输出续写仍需独立验收。[验证记录](../VALIDATION.md)
