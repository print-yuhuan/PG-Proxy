# PG Proxy 0.5.2

「检查凭证」现在固定使用 **Gemini 3.8 Flash**（`gemini-3.8-flash`）发送一次真实短文本生成请求。此前，检查选中的高级模型可能需要额外权限，导致同一份有效凭证出现检查失败。升级后，可在原凭证卡片上点「检查凭证」重新检测。

检查通过表示该账号当时可以调用 Gemini 3.8 Flash。若账号目录中缺少该模型，应用会显示原因并结束检查。通过 OpenAI 或 Gemini 兼容接口生成时，客户端仍按需指定模型，能否调用取决于账号权限。

正式 APK 的版本码为 **52**，适用于 Android 9 及以上的 ARM64 手机。使用 0.5.0 或 0.5.1 正式包的用户可直接覆盖安装，保留凭证、设置和浏览器会话。[安装与签名说明](../MAINTENANCE.md#安装与后续更新)
