# PG Proxy 0.3.1

登录连接中断后，自动尝试继续。

**版本：0.3.1 · 版本码：31 · Android 9+ · arm64-v8a**

[下载安装包](https://github.com/print-yuhuan/PG-Proxy/releases/tag/v0.3.1) · [使用说明](../../README.md#快速开始) · [问题反馈](https://github.com/print-yuhuan/PG-Proxy/issues)

## 更新内容

- **登录连接重置自动恢复。** 在已观察到可信 Google 登录跳转后，遇到“错误分类 3 · 错误代码 147”，应用会使用原浏览器会话自动打开 Playground，继续正常的页面检查与凭证导入流程。
- **避免重复跳转。** 每个登录窗口最多自动尝试一次，重复错误回调不会不断触发恢复；手动重试也不会重置自动尝试次数。
- **失败原因更清楚。** 再次加载失败或 30 秒内未完成页面加载时显示具体提示，保留“重试当前页面”“打开 Playground”和“返回”入口，浏览器会话继续保留。
- **完善恢复任务清理。** 返回、关闭页面或进入凭证导入时取消待执行的恢复；恢复结束后取消短暂提示，避免状态显示滞后。

此前针对 `accounts.youtube.com` 登录跳转的精确主机放行仍然保留。那次问题属于跳转被拦截，当前修复处理网络连接重置，两者不是同一种错误。证书校验、原生 Firefox UA、页面信任和凭证导入确认机制保持不变。

## 安装与升级

下载 Release 附件中的 `PG-Proxy-0.3.1-arm64-v8a-release.apk`。正式签名沿用 0.2.0／0.3.0，可正常覆盖这两个正式版本；常规升级无需卸载或清除数据。旧 0.1.0 或其他签名的安装包须先核对[签名与升级说明](../MAINTENANCE.md#安装与后续更新)。

公开附件提供 APK、SHA-256 校验清单和 `BUILD_INFO.json`。源码提交、架构、签名证书指纹与实际文件哈希以本次 Release 附件为准；正式签名不是第三方安全认证。

## 验证与边界

0.3.1 新版 Debug 包已在默认 **Pixel_10_API_37_Debug / Android 17 / x86_64** 重新构建、覆盖安装并验证：16 项 JVM、853 项 Python、37 项常规 Android 回归，以及 1 个登录恢复综合用例的 10 个检查点通过。综合用例启动真实 Gecko 与登录 Activity，并通过合成错误检查自动恢复、重复回调、实际 30 秒超时、安全错误、返回取消和导入门禁。

开发包和本次 0.3.1 发布包分别记录版本与哈希，详见[验证记录](../VALIDATION.md#031--2026-10-31-登录恢复发布)。本轮未操作真机，未在 ARM64 设备安装运行正式附件，未重新完成真实 Google 登录后连接重置、自动恢复并导入凭证的端到端测试，也未重新执行真实模型生成。模拟器与故障注入结果不能替代这些验收。

自动恢复不保证所有 Google 登录故障都能解决。首次打开页面失败、证书错误、不受信任的地址和 Google 明确拒绝登录不会通过此机制绕过；仍需按网站要求完成账号验证，并检查网络、地区和账号资格。
